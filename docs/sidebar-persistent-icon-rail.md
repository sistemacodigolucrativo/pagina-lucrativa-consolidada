# Sidebar persistente por ícones

A navegação dos painéis inicia recolhida como uma barra lateral estreita, exibindo somente os ícones e o estado ativo.

Um único botão no topo alterna entre os estados recolhido e expandido. No estado expandido, os rótulos e agrupamentos existentes são exibidos sem alterar rotas, permissões ou hierarquias.

No mobile, esta sidebar específica permanece visível como trilho de ícones. A expansão revela os rótulos sobre a área de conteúdo, preservando a largura útil do painel quando recolhida.
