Script Installation Tutorial

Step 1: Create a Database from your hosting "Control Panel/cPanel" and remember to add a user to database if you are using cPanel X and remember DB name and password.

Step 2: Go to "Script-Path/config.php" and edit it to your database setting also Script-Path/install/config.php.

         $dhost                     = "localhost";   //usually localhost, or ip
         $dusername                = "admin";                // database user
         $dpassword                = "240188";      // database pass
         $ddatabase                = "scriptbux";   // database name
         $pro_click                         = "30";           // default 30 seconds, Premium member visit timer
         $free_click                        = "45";                   // default 45 seconds, Free member visit timer
         $script_path              = "http://localhost/scriptbux"; // your script have isntalled, do not include "/" slash at the end

Step 3: Upload all files in Script Folder to your FTP.

Step 4: To install ScriptBux script simplely just locate your browser to http://yoursiteurl.com/setup.php if everything is good it should only give you lots of green text if not then it will give you MySQL errors.

Step 5: Delete setup.php and /install/ folder with contents above from your site.

Step 6: Go to "Script-Path/adsense.html" and edit it to your google adsense account, or keep it empety to Un-Display google adsense on your page.

Script Configuration


Editing Timer :
Open "config.php", Go to line 15 until 16 or above get :
        
         $pro_click                = "30";          // default 30 seconds
         $free_click               = "45";          // default 45 seconds

NOTE : Look at the line 15 This for that is timer for "PREMIUM MEMBER" and at line 16 is timer other.
        
30 mean the timer 30 seconds and 45 mean the timer 45 seconds, change what do you want visitor visit timer. If you wish 20 seconds, you must change it 20...

Editing site name to image logo at surf section :
Open "view.php", Go to line 98 or above get :
        
         <font size="6"><?=$config["site_name"]?></font> 
        
Replace it with

         <img src="where your logo located" border="0" alt="<?=$config["site_name"]?>" title="<?=$config["site_name"]?>">
